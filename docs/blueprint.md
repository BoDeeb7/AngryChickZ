# **App Name**: Velozi

## Core Features:

- Product Catalog & Filtering: Browse a multi-category product catalog with high-quality images and filter products by various attributes and categories.
- Shopping Cart Management: Add products to a dynamic slide-out mini-cart, adjust quantities, and view real-time subtotal calculations.
- User Authentication & Profiles: Secure user registration, login, and personalized profile management for tracking orders and preferences.
- Product Search: An interactive search bar with micro-interactions for efficient product discovery across the platform.
- Admin Product & Inventory Management: A simplified dashboard for sellers to add new products, manage inventory status, and view basic sales metrics.
- AI-Powered Headline Tool: Generate catchy and impactful marketing headlines for product promotions or the Hero Section based on key product information, leveraging a generative AI tool.
- Interactive Utility Calculator: A sleek, collapsible panel featuring a custom calculator for quick utility tasks like discount simulation or currency conversion.

## Style Guidelines:

- Background Color: Deep charcoal/black (#09090B) to establish an ultra-modern dark mode foundation, providing a canvas for vibrant accents.
- Primary Color: Fuchsia (#D946EF) for primary interactive elements, highlights, and glowing effects, ensuring strong contrast against the dark background.
- Accent Color: Electric Purple (#8B5CF6) used to complement the primary fuchsia, especially for gradients, secondary highlights, and providing visual depth.
- Headlines will use 'Space Grotesk' (sans-serif) for a modern, techy, and cinematic feel. Body text will utilize 'Inter' (sans-serif) for its readability and contemporary, neutral aesthetic.
- Lucide React icons will be styled to match the dark mode, featuring high contrast and subtly glowing appearances when interacting, aligning with the premium feel.
- The layout emphasizes full-screen, cinematic hero sections and well-organized product grids, with a sticky glassmorphism navbar and a collapsible floating utility panel. Design is fully responsive for desktop and mobile.
- Subtle, smooth hover transitions across interactive elements, glassmorphism effects with backdrop blur, and interactive CTA buttons that glow. Dynamic elements like a product carousel and animated filter states enhance the immersive experience.
